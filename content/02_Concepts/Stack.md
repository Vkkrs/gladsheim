# Stack
## Definition
Die Aufstellung vor dem Eingang. Alle an einer Seite der Tür, dicht hintereinander. Reihenfolge vorher festgelegt. Jeder weiß ob er rechts oder links geht.
```
[Tür]
  1 - Erster Mann (geht rechts oder links)
  2 - Zweiter Mann (geht gegenüber)
  3 - TL (Kontrolle)
  4 - Letzter Mann (Sicherung Flur)
```
Die Reihenfolge rotiert nach jedem geklärten Raum.
