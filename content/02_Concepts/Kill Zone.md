# Kill Zone
## Definition
Der Bereich in dem der Feind bei einem Hinterhalt bekämpft wird. Bei einem [[BD4 - React to Ambush|Ambush]]: der Bereich in dem das Feuer konzentriert wird. Bei einem eigenen Ambush: der Bereich den das Assault Element und das Support Element abdecken.
## Bei eigenem Ambush
Die Kill Zone wird vorher festgelegt. Alles Feuer wird auf diesen Bereich konzentriert. Security Elements verhindern dass der Feind aus der Kill Zone entkommen kann.
## Bei feindlichem Ambush
Du stehst IN der Kill Zone. Raus da. Bei Near Ambush: durch den Feind hindurch. Bei Far Ambush: Deckung, Feuer, auf Flankenangriff warten.
