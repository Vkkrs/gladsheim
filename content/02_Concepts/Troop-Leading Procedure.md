# Troop-Leading Procedure
## Definition
8-Schritte-Planungsprozess von "Auftrag erhalten" bis "los". 1. Receive Mission, 2. Issue WARNO, 3. Make Plan, 4. Start Movement, 5. Reconnoiter, 6. Complete Plan, 7. Issue OPORD, 8. Supervise.
## Zeitregel
Maximal ein Drittel der verfügbaren Zeit für eigene Planung. Zwei Drittel für die Untergebenen.
## MilSim-Kurzform
1. Auftrag klären, 2. Team vorwarnen, 3. Plan machen, 4. OPORD geben, 5. Los.
