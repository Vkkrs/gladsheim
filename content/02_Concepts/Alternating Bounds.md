# Alternating Bounds
## Definition
Variante von [[Bounding Overwatch]]. Element A sichert. Element B springt an A vorbei. Dann sichert B, A springt an B vorbei. Schneller als [[Successive Bounds]], aber schwerer zu kontrollieren weil die Elemente ständig die Positionen tauschen.
## Verwandte Konzepte
- [[Successive Bounds]]
- [[Bounding Overwatch]]
