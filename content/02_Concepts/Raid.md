# Raid
## Definition
Schneller Angriff auf eine bekannte Position. Rein, Auftrag erfüllen, raus. Die Position wird nicht gehalten. Ablauf: Annäherung → Assault Position → Angriff → Auftrag erledigen → Rückzug zum [[Objective Rally Point|ORP]] → Rückmarsch.
