# Hallway Movement
## Definition
Bewegung in Fluren zwischen Räumen. Fire Team in File entlang einer Wand. Waffen zeigen abwechselnd in verschiedene Richtungen. Jede Kreuzung wird wie eine [[Danger Area]] behandelt.
