# Successive Bounds
## Definition
Variante von [[Bounding Overwatch]]. Element A sichert. Element B springt vor bis auf Höhe von A. Dann sichert B, A springt vor bis auf Höhe von B. Einfacher zu kontrollieren als [[Alternating Bounds]], aber langsamer.
## Verwandte Konzepte
- [[Alternating Bounds]]
- [[Bounding Overwatch]]
