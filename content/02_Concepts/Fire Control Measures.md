# Fire Control Measures
## Definition
Methoden zur Steuerung des Feuers im Sektor:
- **Feuerkommandos** - Richtung, Ziel, Entfernung, Feuerart
- **Target Reference Points (TRPs)** - Festgelegte Geländepunkte. "Feuer auf TRP 1" statt "Feuer auf den Baum links"
- **Engagement Areas** - Bereiche in denen der Feind bekämpft wird
