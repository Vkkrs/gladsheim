# Linear Danger Area
## Definition
Schmale Danger Area: Straße, Weg, Pfad, Fluss, Zaun, Eisenbahnlinie. Wird rechtwinklig überquert, nicht parallel dazu gelaufen.
## Ablauf
Near Side Security → Far Side Security → Rest überquert → Near Side als letztes. Siehe [[Actions at Danger Areas]] für Details.
