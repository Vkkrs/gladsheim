# Fire Team File

> **FM 7-8 Referenz:** Ch.2, 2-7b

## Übersicht

Alle vier Soldaten in einer Reihe hintereinander. Wird verwendet wenn Wedge nicht möglich ist.

## Diagramm

```
TL
AR
GRN
R
```

## Einsatzzweck

- **Wann verwenden:** Enges Gelände, dichtes Unterholz, schmale Pfade, Gebäudebewegung, Nacht mit schlechter Sicht
- **Vorteile:** Minimale Breite, maximale Kontrolle, alle sehen den Vordermann
- **Nachteile:** Kein Flankenfeuer, Treffer von der Seite trifft potentiell alle

## MilSim-Anwendung

Im Wald oder bei Nacht oft die einzig praktische Option. Wenn du File gehst, weiß jeder: wir sind eng zusammen, Flanken sind offen. Erhöhte Wachsamkeit zu den Seiten.
